# SCS IMU 调试

用飞特 SCS 协议读取 IMU 板，并按时间画出姿态、陀螺仪、加速度和四元数。本目录不依赖仓库里的其它文件，整夹拷走即可。

调试串口和 SCS 总线不是同一路。调试口 115200，上电先打印 `scs id=200 baud=1000000 cfg=default`（Flash 里改过则为 `cfg=flash` 和实际值），IMU 初始化成功后再打印 `imu ok`。图形程序要接舵机总线，波特率和 ID 以这行打印为准。之后每秒一行 `scs stat`。

| 字段 | 含义 |
| --- | --- |
| `rx` | 总线上收到的字节。一直是 0 说明这路 USART 没听到总线 |
| `other` | 校验通过、但不是本机 ID 的帧。在涨而 `tx` 不动，说明听得到舵机，没有人叫到这块板的 ID |
| `bad` / `ferr` / `nerr` | 校验失败或线路错误，常见于波特率不一致 |
| `tx` | 本机发出的应答次数 |
| `ovr` | 接收溢出。总线很忙时若持续增加，帧会丢 |
| `last` | 最后收到的原始字节 |

发给本机的 PING、WRITE、SYNC READ 会马上多打一行，例如 `scs ping id=200`。READ 最多每 500 ms 打一行，避免 50 Hz 轮询把调试口堵死。

## 运行

需要 Python 3.9 及以上，界面使用标准库 tkinter。

```bash
pip install -r requirements.txt
python scs_imu_gui.py
```

协议组帧和半精度解码可以不打开界面自检：

```bash
python scs_imu_gui.py --check
```

## 界面

1. 选择串口和波特率，点连接。程序只单播当前 ID（默认 200），读到型号 `0x4955` 才开始轮询。总线上的舵机会被跳过，不会去读它们的内存。ID 若不是 200，点「查找 IMU」：按 ID 逐个单播，只核对型号，找到 IMU 即停。
2. 右侧四条曲线横轴都是时间。在曲线上移动鼠标可读该时刻的数值，滚轮缩放时间窗口。曲线图例可单独开关。
3. 「物理量」显示 dps、g 和度；「原始计数」把陀螺仪和加速度改成芯片 LSB。四元数两种模式下都是解码后的数。
4. 左侧是当前一帧：型号 `0x4955`、状态位、采样计数，以及地址 124 起 20 字节的十六进制。

「写入 Flash」会改设备 ID（地址 5）或波特率枚举（地址 6），掉电保留。改 ID 时这一帧应答仍用旧 ID。改波特率要等应答发完，程序再把本机串口切到新速率。

## 读到的数据

单播 READ，起始地址 124，长度 20，小端。

| 地址 | 内容 |
| --- | --- |
| 124 | 陀螺仪 X/Y/Z，`i16`，±500 dps，17.50 mdps/LSB |
| 130 | 旋转向量 X/Y/Z，IEEE754 binary16 |
| 136 | 加速度 X/Y/Z，`i16`，±4 g，0.122 mg/LSB |
| 142 | 采样计数，`u8`，每来一帧加 1，255 后回绕 |
| 143 | 状态。bit0 在线，bit1 已有四元数，bit2 已有陀螺仪或加速度 |

`w = sqrt(max(0, 1 - x² - y² - z²))`。x、y、z 全为 0 且 bit1 未置位时，表示 SFLP 还没有输出。姿态角由这个四元数算出，是传感器坐标，没有套安装旋转。

陀螺仪换算：`rad/s = count × 0.0175 × π / 180`。

波特率枚举：0 = 1 Mbps，1 = 500 kbps，2 = 250 kbps，3 = 128 kbps，4 = 115200，5 = 76800，6 = 57600，7 = 38400，8 = 19200，9 = 14400，10 = 9600，11 = 4800。
